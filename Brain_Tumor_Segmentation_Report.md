# Brain Tumor Segmentation Using 2D UNet

## 1. Literature Review

Brain tumor segmentation is a critical task in medical image analysis, aiding diagnosis, treatment planning, and monitoring. Manual segmentation is time-consuming and prone to variability, motivating automated methods. Deep learning, particularly convolutional neural networks (CNNs), has revolutionized medical image segmentation.

The UNet architecture, introduced by Ronneberger et al. (2015), is a widely adopted CNN model for biomedical image segmentation. It features an encoder-decoder structure with skip connections, enabling precise localization and context capture. Variants of UNet have been applied successfully to brain tumor segmentation challenges such as the BraTS dataset, which provides multi-modal MRI scans with expert annotations.

## 2. Implementation

This project implements a 2D UNet model for brain tumor segmentation on MRI slices. The key components include:

- **Data Preprocessing:** 3D MRI volumes and corresponding tumor masks are sliced along the z-axis into 2D slices using the `preprocess_slices.py` script. This converts volumetric data into manageable 2D images (128x128 pixels with 4 channels) and masks, saved as `.npy` files for training and validation.

- **Dataset:** The `dataset_fixed.py` defines a PyTorch Dataset class `BrainTumor2DSliceDataset` that loads these 2D slices and applies any necessary transformations.

- **Model:** The `unet_model.py` implements the UNet architecture with double convolution blocks, downsampling, upsampling, and skip connections. The model takes 3-channel input images and outputs a single-channel binary mask predicting tumor regions.

- **Training and Validation:** The model is trained using binary cross-entropy loss (BCE) and evaluated on validation slices. The trained model weights are saved as `unet_model_brats.pth`.

- **Frontend:** A Flask web application (`webapp/app_fixed.py`) serves an interactive frontend where users can select slice indices to visualize the input image, ground truth mask, and predicted mask. The frontend uses matplotlib to convert tensor images to base64-encoded PNGs for display.

## 3. Generating Results

Results are generated by running the trained UNet model on validation 2D slices. For each selected slice, the model outputs a probability mask, which is thresholded to produce a binary segmentation mask. The frontend visualizes these alongside the input image and ground truth mask, enabling qualitative assessment.

## 4. Experiential Learning - Outcome: Results and Analysis

The project demonstrates the feasibility of 2D UNet for brain tumor segmentation on MRI slices. The interactive frontend facilitates exploration of model predictions across slices, highlighting strengths and limitations.

Key observations include:

- The model effectively segments tumor regions in many slices, capturing shape and location consistent with ground truth.

- Some slices may show false positives or missed tumor areas, indicating room for improvement in model accuracy.

- The slicing approach simplifies 3D data handling but may lose inter-slice contextual information, suggesting potential benefits from 3D or hybrid models.

- Visualization aids in understanding model behavior and supports iterative refinement.

Overall, this project provides hands-on experience with medical image preprocessing, deep learning model implementation, and deployment of an interactive visualization tool, reinforcing concepts in biomedical image analysis and deep learning workflows.
